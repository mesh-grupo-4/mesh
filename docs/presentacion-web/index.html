El problema

En el camino, el grupo se estira.

  • ¿Quién se quedó atrás?

Lo que hay hoy

Las apps miran a una persona.

StravaKomootGarminGoogle MapsLife360

Resuelven el rendimiento de cada uno o cómo llegar de un punto a otro.

Ninguna entiende qué le pasa al grupo como conjunto.

La solución

Mesh mira al grupo.

Un motor de eventos en el servidor compara cada posición GPS con la ruta planificada y avisa solo, sin que nadie tenga que hacerlo.

Conclusiones

87 historias. Todas implementadas.

  • Receso, mesas y muestra→ajustamos la capacidad
  • Un stack nuevo→historias compartidas
  • Un mapa que no alcanzaba→Google Maps + OSM
  • Un alcance que cambió→cambio formal con el PO
  • Rutas sin señal→offline-first
  • Depender de la IA→siempre con revisión humana

Lecciones aprendidas

Si arrancáramos de nuevo…

Repetiríamos

  • Firebase para la autenticación
  • API primero y deploy temprano
  • Un plan B para los mapas

Cambiaríamos

  • Planificar con el calendario académico
  • Probar la tecnología antes de diseñar
  • Registrar cada cambio de alcance
